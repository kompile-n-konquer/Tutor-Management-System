# Sprint 1 
*(2026-08-02 → 2026-08-25)*

*(Taken directly from our Gitea Milestone for Sprint 1, used as the
sprint's defined goal and scope.)*

## Goal

Get the project's foundational infrastructure in place — authentication,
database connectivity (local and Azure), CI/CD, testing setup, and initial
documentation content — so feature development in Sprint 2 isn't blocked
on missing scaffolding. This milestone also covers the Initial Design &
Dev Plan required for Milestone 1, scored separately from setup
implementation.

## Scope — Implementation

- Working authentication (sign up, sign in, password reset, etc.)
- A documented local database setup so every teammate can run a matching
  local database
- Proven frontend ↔ backend ↔ database connectivity end to end
- Azure infrastructure provisioned and reachable
- Automated deployment to Azure on merge to `main`
- Automated test runs on every PR
- A working test pattern (Jest) for both frontend and backend
- Architecture and Database Schema pages on the documentation site

**Initial Design & Dev Plan** is also part of this milestone's scope but
is scored separately — see the *Initial Design and Dev Plan* page for
that content.
