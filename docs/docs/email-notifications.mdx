# Email Notification Service

This document provides a comprehensive overview of the email notification service implemented in the Tutor Management System, which uses **Brevo** as the email provider.

## What is Brevo?

Brevo is a customer communication platform with a transactional email API. Applications submit emails to its REST API (v3), and Brevo handles delivery, tracking and reporting. In this project the backend calls the API directly over HTTPS with `fetch` — no email SDK dependency is required.

## Why Brevo Was Chosen

1. **Simple HTTP API**: A plain REST endpoint (`POST /v3/smtp/email`) — callable with the built-in `fetch`, so the backend needs no extra email dependency.
2. **Deliverability**: Brevo runs established transactional-email infrastructure and supports verified senders/domains, reducing the chances of emails ending up in spam folders.
3. **Tooling**: The Brevo dashboard provides delivery logs and sender verification, which helps during development and debugging.
4. **Generous Free Tier**: It provides a sufficient number of free emails to cover development, testing, and early production usage without immediate costs.

## Implementation Details

In the Tutor Management System, Brevo is used to trigger transactional emails across various workflows:

- **Account Management**: Welcome emails and password reset links.
- **Application Status**: Notifying students about the outcome of their tutoring applications (accepted, rejected, waitlisted).
- **Timesheet Updates**: Informing tutors when their submitted timesheets are approved or queried by organizers.
- **Session Notifications**: Alerts regarding assigned sessions, excuse requests, and cover assignments.

### Security and Configuration

- **API Keys**: Requests authenticate with an API key sent in the `api-key` header, read from the `BREVO_API_KEY` environment variable (never committed).
- **Sender Identity**: Emails are sent as TutorFlow from the address configured in `BREVO_SENDER_EMAIL`, which must be a verified sender in the Brevo dashboard to ensure authenticity and maintain deliverability.

## Conclusion

By using Brevo, the Tutor Management System can reliably and efficiently deliver critical updates to tutors, students, and organizers, enhancing the overall user experience and ensuring timely communication.
