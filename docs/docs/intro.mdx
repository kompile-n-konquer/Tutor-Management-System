# Introduction

Welcome to the documentation for the **Tutor Management System** - a platform built for the University
of the Witwatersrand's School of Computer Science and Applied Mathematics, developed as part of
COMS3011A Project 1.

## What is this?

The Tutor Management System helps an organiser assign tutors to courses based on their marks,
availability, and weekly hour limits, all from a single allocation board. It also lets:

- **Tutors** log their hours, submit timesheets, and excuse themselves from sessions they can't make
- **Students** apply to tutor and volunteer for overflow work
- **Organisers** manage allocations, approve timesheets, and track hours across the school

## Who this documentation is for

- **Team members** setting up the project locally or contributing a feature
- **Markers/reviewers** wanting to understand the system's architecture and data model
- **Anyone** curious how the platform is structured
